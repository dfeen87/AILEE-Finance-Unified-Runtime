# AILEE Finance Unified Runtime v16.0.0: Layer 16 — Deterministic Anomaly Detection & Market Condition Layer

## Executive Summary

AILEE Version 16.0.0 introduces **Layer 16: Real-Time Market Condition Intelligence & Anomaly Detection Layer** (`ANOMALY_DETECTION_V1`). Layer 16 operates as an allocator-free, low-latency, non-directive advisory subsystem designed to continuously monitor live market data feeds for statistically abnormal conditions across volatility expansion, order book liquidity displacement, and asset pair correlation breakdowns.

In accordance with AILEE's strict safety posture, Layer 16 is **strictly advisory-only**. It emits human-readable, cautionary alerts highlighting observed market patterns with zero execution recommendations, buy/sell triggers, or accusations of wrongdoing or manipulation.

---

## Architectural Principles

1. **64-Byte Cache Alignment**: All core structs (`AnomalyState`, `AnomalyAdvisory`, `AnomalyObservabilityMetrics`, `AnomalyTraceStep`, `AnomalyConfig`) are exactly 64 bytes (`alignas(64)`), ensuring single cache-line residency, predictable CPU cache behavior, and zero heap allocations in hot paths.
2. **Stream Statistics & EWMA**: Evaluates intraday volatility expansion via fast EWMA ratios, order book L1/L2 depth thinning percentages, and unrolled $2 \times 2$ covariance matrix estimators for pair correlation tracking.
3. **Multi-Tick Debouncing / False Positive Suppression**: Enforces configurable consecutive-tick debounce targets (default: 3 bars for volatility, 3-5 bars for liquidity, 5 bars for correlation breaks) before confirming an active advisory.
4. **Non-Directive Cautionary Messaging**: Generates human-readable, context-rich alerts that explicitly avoid prescriptive trading advice or subjective allegations.
5. **Spire WebSocket & Audit Trail Ingestion**: Broadcasts active anomaly advisories in structured JSON over `aille_spire` WebSocket channels and writes trace records to `logs/anomaly_trace.log`.

## Core Struct Specifications (C++)

```cpp
struct alignas(64) AnomalyState final {
    float last_price;             ///< Latest asset trade price
    float volume;                 ///< Latest interval volume
    float bid_size;               ///< Top-of-book L1 bid size
    float ask_size;               ///< Top-of-book L1 ask size
    float ewma_volatility;        ///< Fast intraday EWMA volatility estimate
    float baseline_volatility;    ///< Historical 30-day baseline volatility
    float baseline_depth;         ///< Historical average top-of-book total depth (bid_size + ask_size)
    float pair_last_price;        ///< Correlated pair asset trade price
    float rolling_correlation;    ///< Calculated rolling Pearson correlation with pair asset
    float expected_correlation;   ///< Historical benchmark correlation for asset pair
    std::uint8_t vol_debounce_count;  ///< Consecutive volatility anomaly observations
    std::uint8_t liq_debounce_count;  ///< Consecutive liquidity displacement observations
    std::uint8_t corr_debounce_count; ///< Consecutive correlation break observations
    std::uint8_t symbol_id;           ///< Numeric symbol identifier
    std::uint8_t _padding[20];
};
static_assert(sizeof(AnomalyState) == 64, "AnomalyState must be 64 bytes");
```
